# 폰에서 바로 실행하기 (Expo Go)

플레이스토어나 앱스토어에 앱을 정식 등록하지 않아도, **오늘 당장** 내 휴대폰에서 "마이 튜브" 화면을 열어볼 수 있습니다. Expo에서 제공하는 **Expo Go**라는 무료 앱을 이용하는 방법입니다.

> 이 방법은 앱 화면과 **카테고리 자동 분류 기능을 폰에서 미리 체험**하는 용도입니다. 지금은 데모(예시) 데이터로 동작하며, 데이터는 서버가 아니라 **내 기기 안에만** 저장됩니다.
> 폰에서 **유튜브 로그인까지** 하려면 준비가 조금 더 필요한데, 그 부분은 맨 아래 항목에서 짧게만 짚어 드립니다(지금은 안 해도 됩니다).

준비물: **휴대폰 1대**, **컴퓨터 1대**, 그리고 **둘 다 같은 Wi-Fi에 연결**되어 있어야 합니다.

---

## 1단계. 휴대폰에 Expo Go 앱 설치하기

휴대폰 기종에 맞게 하나만 설치하면 됩니다.

- **안드로이드폰**: 휴대폰에서 **Play 스토어**를 엽니다 → 위쪽 검색창에 `Expo Go` 를 입력 → 검색 결과에서 **Expo Go**(하늘색 아이콘)를 찾아 **[설치]** 버튼을 누릅니다.
- **아이폰**: 휴대폰에서 **App Store**를 엽니다 → 아래 **[검색]** 탭을 누르고 `Expo Go` 를 입력 → **Expo Go**를 찾아 **[받기]** 버튼을 누릅니다.

설치가 끝나면 앱을 한 번 열어 봅니다. (로그인은 안 해도 됩니다. 그냥 열려 있기만 하면 됩니다.)

---

## 2단계. 컴퓨터에서 앱 실행 준비하기

컴퓨터에서 **터미널**(명령어를 입력하는 검은 창)을 엽니다.

- **Windows**: 시작 메뉴에서 `PowerShell` 을 검색해 엽니다.
- **Mac**: `터미널`(Terminal)을 검색해 엽니다.

그런 다음, 프로젝트 폴더로 이동합니다. 아래 명령을 그대로 복사해 붙여넣고 **Enter**를 누르세요. (따옴표 안 경로가 이 프로젝트가 저장된 위치입니다.)

```bash
cd "C:\Users\scpar\Project\My_youtube"
```

> 붙여넣을 때 PowerShell에서는 **마우스 오른쪽 클릭**으로 붙여넣기가 됩니다.

폴더로 이동했으면, 아래 명령을 입력하고 **Enter**를 누릅니다.

```bash
npx expo start
```

> - 처음 실행하면 필요한 파일을 준비하느라 잠깐(수십 초~몇 분) 걸릴 수 있습니다. 그대로 기다립니다.
> - `npx: command not found` 또는 `'npx'을(를) 인식할 수 없습니다` 같은 오류가 나면 컴퓨터에 **Node.js**가 아직 없다는 뜻입니다. [nodejs.org](https://nodejs.org) 에서 **LTS** 버전을 설치한 뒤, 터미널을 **완전히 닫았다가 다시 열고** 2단계를 처음부터 다시 하세요.

---

## 3단계. 화면에 뜬 QR코드 스캔하기

`npx expo start` 가 정상적으로 실행되면, **터미널 창 안에 네모난 QR코드**가 나타납니다.
(터미널이 좁아 QR코드가 잘려 보이면, 창을 크게 넓힌 뒤 QR코드가 다시 그려지도록 터미널에서 알파벳 **`r`** 키를 한 번 누르세요.)

휴대폰 기종에 따라 스캔 방법이 다릅니다.

- **안드로이드폰**: 1단계에서 설치한 **Expo Go 앱을 엽니다** → 첫 화면에 있는 **[Scan QR code]**(QR 코드 스캔) 버튼을 누릅니다 → 휴대폰 카메라를 컴퓨터 화면의 QR코드에 맞춥니다.
  (안드로이드는 기본 카메라 앱으로 찍으면 Expo Go로 잘 연결되지 않으니, **반드시 Expo Go 앱 안의 스캔 버튼**을 쓰세요.)
- **아이폰**: 휴대폰의 기본 **카메라 앱을 엽니다**(Expo Go가 아니라 카메라입니다) → QR코드에 카메라를 맞추면 화면 위에 **작은 알림 배너**가 뜹니다 → 그 배너를 **탭(터치)** 하면 Expo Go가 자동으로 열립니다.

---

## 4단계. 폰에서 앱 실행 확인하기

잠시 뒤 휴대폰에서 **"마이 튜브" 앱 화면이 열립니다.**

- 처음에는 앱 파일을 내려받느라 로딩 막대가 잠깐 지나갑니다. 그대로 기다리면 됩니다.
- 화면이 뜨면 하단 탭(**구독** / **설정**)을 눌러 이동하거나, 데모 데이터로 **카테고리 자동 분류** 기능을 직접 눌러볼 수 있습니다.
- 컴퓨터에서 코드를 고치면 폰 화면도 **자동으로 새로고침**됩니다.
- 실행을 멈추려면 터미널 창을 클릭한 뒤 **Ctrl + C** 를 누릅니다.

---

## 잘 안 될 때: 튜널(tunnel) 모드 사용하기

QR코드를 스캔했는데 폰에서 **계속 로딩만 되고 앱이 안 열리는 경우**, 대부분 컴퓨터와 폰이 서로를 못 찾는 **네트워크 문제**입니다. 다음을 먼저 확인하세요.

1. 컴퓨터와 폰이 **정확히 같은 Wi-Fi**에 연결돼 있나요? (예: 집 공유기의 `2.4GHz`와 `5GHz`가 다른 이름이면 서로 다른 망으로 잡힐 수 있습니다. 이름이 완전히 같은 Wi-Fi에 둘 다 연결하세요.)
2. 회사·학교 Wi-Fi나 공용 Wi-Fi는 기기 간 연결을 막아 두는 경우가 많습니다.

위를 확인해도 안 되면, 터미널을 클릭하고 **Ctrl + C** 로 멈춘 뒤 아래 명령으로 다시 실행합니다.

```bash
npx expo start --tunnel
```

이렇게 하면 Expo의 중계 서버를 거쳐 연결되므로, **같은 Wi-Fi가 아니어도**(심지어 폰이 데이터 통신 중이어도) 대부분 연결됩니다. 대신 화면 갱신이 조금 느려지니, 잘 되던 환경에서는 그냥 `npx expo start` 를 쓰는 편이 빠릅니다.

> 튜널 모드를 처음 쓰면 추가 도구(`@expo/ngrok`) 설치를 묻는 경우가 있습니다. 물어보면 키보드에서 **`y`** 를 누르고 **Enter**(예)를 눌러 설치를 진행하세요.

## 참고: 폰에서 "유튜브 로그인"까지 하려면 (지금은 안 해도 됩니다)

위 1~4단계만으로는 **앱 화면과 분류 기능 체험**까지만 됩니다. 폰에서 **실제 유튜브 로그인**(내 구독 목록 불러오기)까지 하려면 두 가지가 더 필요하며, 둘 다 지금 당장 할 일은 아닙니다.

**1) 지금 클라이언트 ID로는 폰에서 로그인되지 않습니다.**
지금까지 만든 유튜브 연결용 **클라이언트 ID는 "웹 애플리케이션" 유형**입니다. 컴퓨터 웹브라우저(리디렉션 주소 `http://localhost:8081`)에서는 이걸로 로그인이 되지만, **폰 앱 안에서는 이 웹용 ID로 유튜브 로그인이 되지 않습니다.** 폰에서 로그인하려면 나중에 **Google Cloud Console**에서 안드로이드/iOS용 클라이언트를 각각 추가해야 합니다.

- **[사용자 인증 정보 만들기] → [OAuth 클라이언트 ID]** 를 누른 뒤,
- 애플리케이션 유형에서 **"Android"** 를 골라 패키지 이름 `com.favorit.tubeorganizer` 를 넣은 안드로이드용 클라이언트,
- **"iOS"** 를 골라 번들 ID `com.favorit.tubeorganizer` 를 넣은 iOS용 클라이언트를 각각 만듭니다.

**2) 로그인은 "Expo Go"가 아니라 "개발 빌드"에서 됩니다.**
폰에서의 유튜브 로그인은 우리 앱 고유의 주소(scheme `favorit`)로 되돌아오는 과정이 필요한데, **Expo Go 앱 안에서는 이 고유 주소 방식이 동작하지 않습니다.** 그래서 폰 로그인 테스트는 Expo Go 대신 **우리 앱만의 개발용 앱(개발 빌드)** 을 따로 만들어 설치한 뒤에 하게 됩니다.

> 참고로 Google이 지금 앱이 쓰는 예전 로그인 방식(implicit/Token)을 보안 문제로 단계적으로 없애는 중입니다. 그래서 폰 로그인을 붙이는 **다음 단계에서 최신 권장 방식(Authorization Code + PKCE)으로 함께 바꿀 예정**입니다. 요청하는 권한은 지금과 같은 **읽기 전용 구독 목록**(`youtube.readonly`)뿐이라, 내 유튜브에 무언가를 바꾸거나 올리지는 않습니다.

이 작업들은 손이 조금 가므로 **다음 단계에서 순서대로 안내**합니다. 지금은 위 1~4단계로 **앱 화면과 분류 기능을 폰에서 체험**하는 데 집중하시면 됩니다.
