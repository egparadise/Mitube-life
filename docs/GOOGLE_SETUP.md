# 구글 OAuth 설정 가이드 (유튜브 연결용)

이 가이드는 "마이 튜브" 앱이 내 유튜브 구독 목록을 읽어올 수 있도록, 구글에서 **연결 열쇠(클라이언트 ID)** 를 발급받는 방법을 알려줍니다. 개발 지식이 없어도 순서대로 따라 하면 됩니다.

> **미리 알아두기 (겁먹지 마세요)**
> - 이 앱은 **읽기 전용**입니다. 구독 목록을 "보기"만 하고(권한 이름 `youtube.readonly`), 좋아요·구독·삭제 같은 건 절대 못 합니다.
> - 발급받은 정보(클라이언트 ID)는 **내 기기 안에만** 저장됩니다. 우리 서버로 보내지 않습니다.
> - 아래에서 앱을 **"테스트 모드"** 로 두면, 구글의 복잡한 심사(검증)를 **받지 않아도** 본인 포함 100명까지 바로 쓸 수 있습니다. 혼자 쓰는 앱이니 심사는 필요 없습니다.
> - 준비물: 유튜브 구독을 볼 그 **구글 계정**, 그리고 약 **10분**.

---

## 0. 시작 전에

1. 크롬 같은 웹 브라우저에서 **[console.cloud.google.com](https://console.cloud.google.com)** 에 접속합니다.
2. 유튜브를 보는 **바로 그 구글 계정**으로 로그인합니다. (다른 계정으로 로그인하면 엉뚱한 구독 목록이 나옵니다.)
3. 처음이라면 "서비스 약관 동의" 창이 뜰 수 있습니다. 국가를 고르고 **동의 → 계속**을 누릅니다.

> 화면 언어가 영어로 나오면, 오른쪽 위 프로필/설정에서 언어를 한국어로 바꿀 수 있습니다. 이 가이드는 한국어 UI 기준이며, 영어 명칭도 괄호로 함께 적어둡니다.

---

## 1. 새 프로젝트 만들기

구글에서는 모든 설정을 "프로젝트"라는 상자 하나에 담습니다. 그 상자를 먼저 만듭니다.

1. 화면 **맨 위 파란색 막대 왼쪽**에, 현재 프로젝트 이름(또는 "프로젝트 선택")이 적힌 **드롭다운 버튼**이 있습니다. 그것을 클릭합니다.
2. 뜬 창의 **오른쪽 위 "새 프로젝트"(New project)** 를 클릭합니다.
3. **프로젝트 이름(Project name)** 칸에 알아보기 쉬운 이름을 적습니다. 예: `마이 튜브`
   - 위치(Location)/조직(Organization)은 그대로 두세요. ("조직 없음"이면 정상입니다.)
4. **"만들기"(Create)** 를 클릭합니다.
5. 몇 초 뒤 오른쪽 위 알림(종 모양)에 생성 완료가 뜹니다. 다시 **맨 위 프로젝트 드롭다운**을 눌러 방금 만든 **`마이 튜브`** 을 선택합니다.

> 이후 모든 작업은 이 프로젝트가 **선택된 상태**에서 해야 합니다. 맨 위 막대에 `마이 튜브`이 보이는지 항상 확인하세요.

---

## 2. YouTube Data API v3 사용 설정하기

앱이 유튜브 데이터를 쓰려면, 이 프로젝트에서 유튜브 기능을 **"켜야"** 합니다.

1. 왼쪽 위 **햄버거 메뉴(≡, 줄 3개)** 를 클릭합니다.
2. **"API 및 서비스"(APIs & Services) → "라이브러리"(Library)** 를 클릭합니다.
3. 라이브러리 검색창에 **`YouTube Data API v3`** 를 입력하고 검색합니다.
4. 결과에서 **"YouTube Data API v3"** 를 클릭합니다.
5. 파란색 **"사용"(Enable)** 버튼을 클릭합니다.
6. 잠시 후 API 관리 화면으로 넘어가면 성공입니다.

---

## 3. OAuth 동의 화면 구성하기 (누구에게 물어볼지 설정)

"동의 화면"은 로그인할 때 뜨는 **"이 앱이 당신의 유튜브 구독을 볼 수 있게 허용할까요?"** 창입니다. 그 창을 미리 만들어 둡니다.

> **2026년 변경점**: 예전의 "OAuth 동의 화면" 메뉴는 지금 **"Google 인증 플랫폼"(Google Auth Platform)** 이라는 이름으로 바뀌었고, **개요(Overview) · 브랜딩(Branding) · 대상(Audience) · 클라이언트(Clients)** 같은 탭으로 나뉘어 있습니다.

1. 왼쪽 **햄버거 메뉴(≡) → "API 및 서비스"(APIs & Services) → "OAuth 동의 화면"(OAuth consent screen)** 을 클릭합니다.
   - 여기를 누르면 **"Google 인증 플랫폼"(Google Auth Platform)** 화면으로 연결됩니다.
2. 아직 설정 전이면 파란색 **"시작하기"(Get started)** 버튼이 보입니다. 클릭합니다.
3. 이제 한 페이지짜리 짧은 마법사(4단계)가 순서대로 뜹니다. 아래대로 채웁니다.

   **① 앱 정보(App Information)**
   - **앱 이름(App name)**: `마이 튜브` (로그인 창에 표시될 이름)
   - **사용자 지원 이메일(User support email)**: 드롭다운에서 **본인 이메일**을 선택
   - **"다음"(Next)** 클릭

   **② 대상(Audience) — 여기가 핵심**
   - **"외부"(External)** 를 선택합니다.
     > 일반 구글(gmail) 계정은 "외부"만 선택할 수 있습니다. "내부(Internal)"는 회사(Workspace)용이라 대부분 회색으로 비활성화되어 있습니다. **외부가 맞습니다.**
   - **"다음"(Next)** 클릭

   **③ 연락처 정보(Contact Information)**
   - **이메일 주소(Email address)**: 본인 이메일 입력 (구글이 중요한 공지를 보낼 곳)
   - **"다음"(Next)** 클릭

   **④ 완료(Finish)**
   - **"Google API 서비스: 사용자 데이터 정책에 동의합니다"** 체크박스를 체크
   - **"계속"(Continue) → "만들기"(Create)** 클릭

4. 만들기가 끝나면 **개요(Overview)** 화면으로 돌아옵니다.

### 3-1. 나(테스트 사용자)를 명단에 추가하기 — 반드시!

"외부" 앱은 처음에 **"테스트 중"(Testing)** 상태입니다. 이 상태에서는 **미리 등록한 사람만** 로그인할 수 있으므로, **본인을 명단에 넣어야** 합니다. 이걸 빼먹으면 로그인할 때 `access_blocked` 오류가 납니다.

1. 왼쪽(또는 상단) 탭에서 **"대상"(Audience)** 을 클릭합니다.
2. 아래로 스크롤해 **"테스트 사용자"(Test users)** 항목을 찾습니다.
3. **"사용자 추가"(Add users)** 를 클릭합니다.
4. **본인 구글 이메일**(유튜브 보는 그 계정)을 입력합니다.
5. **"저장"(Save)** 을 클릭합니다.

> **왜 심사가 필요 없나요?**
> "테스트 중" 상태에서는 여기 명단에 넣은 사람(**최대 100명**)만 쓸 수 있고, 그 대신 **구글의 앱 검증(심사)을 받지 않아도 됩니다.** 혼자 쓰는 앱이니 이 상태로 두면 충분합니다. **"게시"(Publish app)는 누르지 마세요** — 누르면 검증 절차가 시작됩니다.
>
> 참고: 이 앱은 유튜브 구독을 읽는 권한을 쓰기 때문에, 테스트 상태에서는 로그인 승인이 **7일 후 만료**됩니다. 가끔 다시 로그인해야 할 수 있는데, 이는 정상이며 오류가 아닙니다.

## 4. OAuth 클라이언트 ID 만들기 (연결 열쇠 발급)

이제 앱이 사용할 **실제 열쇠(클라이언트 ID)** 를 만듭니다. 리디렉션 주소까지 **한 화면에서** 함께 입력하고 마지막에 만들기를 누릅니다.

1. 같은 **"Google 인증 플랫폼"(Google Auth Platform)** 화면에서 왼쪽/상단 탭의 **"클라이언트"(Clients)** 를 클릭합니다.
   - 다른 길: 왼쪽 **햄버거 메뉴(≡) → "API 및 서비스" → "사용자 인증 정보"(Credentials)** 로 가도 됩니다.
2. 위쪽의 **"+ 클라이언트 만들기"(Create client)** 를 클릭합니다.
3. **애플리케이션 유형(Application type)** 드롭다운에서 **"웹 애플리케이션"(Web application)** 을 선택합니다.
   > 스마트폰 앱이지만 **"웹 애플리케이션"** 이 맞습니다. 이 앱은 웹 방식의 로그인 흐름을 쓰기 때문입니다. **"Android"나 "iOS"를 고르지 마세요.** (고르면 뒤에서 클라이언트 ID가 앱과 맞지 않아 로그인이 안 됩니다.)
4. **이름(Name)** 칸에 알아보기 쉬운 이름을 적습니다. 예: `마이 튜브 웹`
5. **아직 맨 아래 "만들기"를 누르지 마세요.** 먼저 다음 5단계에서 주소 두 개를 추가한 뒤 마지막에 만듭니다.

## 5. 주소(원본·리디렉션 URI) 추가하기

로그인 창은 **웹 브라우저에서 실행**(`npm run web`, 주소 `http://localhost:8081`)할 때 이 주소로 열리고 돌아옵니다. 이 주소가 정확히 일치하지 않으면 로그인이 막힙니다(`redirect_uri_mismatch`). 안전하게 **두 곳 모두**에 같은 주소를 넣습니다.

같은 만들기 화면을 아래로 스크롤하면 두 항목이 있습니다.

**① 승인된 JavaScript 원본(Authorized JavaScript origins)**
1. **"+ URI 추가"(Add URI)** 를 클릭합니다.
2. 아래 주소를 **정확히** 입력합니다:

```
http://localhost:8081
```

**② 승인된 리디렉션 URI(Authorized redirect URIs)**
1. **"+ URI 추가"(Add URI)** 를 클릭합니다.
2. **똑같은 주소**를 한 번 더 입력합니다:

```
http://localhost:8081
```

**③ 배포한 사이트(mitube-life)에서도 로그인하려면**
①과 ② **두 곳 모두**에 아래 두 주소를 추가로 넣습니다 (사이트 주소마다 따로 등록해야 합니다).

```
https://mitube-life.web.app
https://mitube-life.firebaseapp.com
```

> **주의 (자주 틀리는 곳)**
> - `localhost`는 반드시 `http`(s 없음)입니다. `localhost`는 예외적으로 `http`가 허용됩니다. 배포 사이트 주소는 `https`입니다.
> - 끝에 슬래시(`/`)를 붙이지 마세요. `http://localhost:8081/` (X)
> - 포트 번호 **8081** 이 정확해야 합니다. (8080 아님)
> - 앞뒤 공백 없이, 그대로 복사해 붙여넣는 것을 권장합니다.

3. 화면 맨 아래 **"만들기"(Create)** 를 클릭합니다.

> **스마트폰 앱(iOS/안드로이드)에서 로그인할 때는?**
> 폰 앱은 브라우저 주소 대신 **앱 자체 주소(`favorit://`)** 로 돌아오므로, 위 `localhost:8081` 주소와는 별개입니다. 지금은 웹으로 먼저 연결하는 것을 기준으로 안내하며, 폰 주소는 여기 따로 넣지 않아도 됩니다.

## 6. 클라이언트 ID 복사해서 앱에 붙여넣기

1. 만들기가 끝나면 **"OAuth 클라이언트가 생성되었습니다"** 같은 안내창이 뜨고, **클라이언트 ID(Client ID)** 가 보입니다.
   - 형태 예시: `123456789012-abc123def456.apps.googleusercontent.com`
   - 옆의 **복사 아이콘**을 눌러 복사합니다.
   > 옆에 **클라이언트 보안 비밀번호(Client secret)** 도 함께 보이지만, 이 앱은 그것을 **쓰지 않습니다.** 따로 저장하거나 앱에 넣을 필요 없이 창을 닫아도 됩니다. **클라이언트 ID만** 있으면 됩니다.
2. 창을 닫아도, 나중에 **"클라이언트"(Clients)** 탭에서 방금 만든 항목(`마이 튜브 웹`)을 클릭하면 클라이언트 ID를 다시 볼 수 있습니다.
3. 이제 **마이 튜브 앱**으로 돌아갑니다.
4. 하단 탭의 **두 번째 탭(설정)** 으로 이동합니다.
5. **"YouTube 연결"** 을 열고, **"OAuth 클라이언트 ID"** 칸을 찾습니다.
   - 참고: 그 화면에 표시된 **"승인된 리디렉션 URI"** 값이 `http://localhost:8081`인지 눈으로 한 번 확인하세요. 5단계에서 등록한 주소와 같아야 합니다.
6. 방금 복사한 **클라이언트 ID를 붙여넣습니다.**
7. **"구글 로그인하고 연결"** 버튼을 누릅니다.
8. 구글 로그인 창이 뜨면, **3-1에서 테스트 사용자로 등록한 바로 그 계정**으로 로그인합니다.
9. **"확인되지 않은 앱"** 경고가 나오면 아래 섹션 안내대로 **고급 → 계속**을 누릅니다. (내가 만든 내 앱이라 안전합니다.)
10. **"마이 튜브이 유튜브 구독 정보를 보려고 합니다"** 화면에서 **"허용"(Allow)** 을 누르면 연결 완료입니다. 잠시 뒤 **"구독" 탭**에 내 채널이 들어오고 자동 분류됩니다.

## "확인되지 않은 앱" 경고, 이렇게 통과합니다

로그인 중 파란/회색 경고 화면이 나오는 건 **정상**입니다. 내 앱이 아직 구글 검증을 안 받았다는 뜻일 뿐, 문제가 아닙니다.

1. 경고 화면 왼쪽 아래의 작은 글씨 **"고급"(Advanced)** 을 클릭합니다.
2. 펼쳐진 아래쪽에서 **"마이 튜브(안전하지 않음)으로 이동"(Go to 마이 튜브 (unsafe))** 을 클릭합니다.
   > "(안전하지 않음)"이라는 표현은 "구글이 아직 검증 안 함"을 뜻할 뿐입니다. **본인이 만든 본인 앱**이므로 진행해도 됩니다.
3. 권한 요청 화면에서 **"허용"(Allow)** 을 누릅니다.

## 자주 겪는 오류와 해결책

| 오류 메시지 | 무슨 뜻인가 | 해결 방법 |
|---|---|---|
| **redirect_uri_mismatch** | 앱이 보낸 돌아올 주소가, 구글에 등록한 주소와 **글자 하나라도 다름** | 4~5단계의 **클라이언트** 설정에서 **승인된 리디렉션 URI**에 `http://localhost:8081`이 **정확히** 있는지 확인. 끝 슬래시(`/`), `https`, 다른 포트(8080 등)를 의심. 그래도 안 되면 슬래시가 붙은 `http://localhost:8081/`도 리디렉션 URI에 **추가로** 등록해 보세요. 수정 후 저장하면 반영까지 몇 분 걸릴 수 있음 |
| **access_blocked / 앱이 확인되지 않음** ("이 앱은 Google의 인증 절차를 완료하지 않았습니다") | 로그인한 계정이 **테스트 사용자 명단에 없음** | **3-1단계**로 가서 **대상(Audience) → 테스트 사용자 → 사용자 추가**에 **로그인하려는 그 이메일**을 넣고 저장. 로그인 계정과 명단 계정이 같은지 확인 |
| **화면에 "확인되지 않은 앱" 경고만 뜨고 못 넘어감** | 검증 안 된 앱의 정상 경고 | **고급(Advanced) → "…(안전하지 않음)으로 이동" → 허용**. (위 섹션 참고) |
| **invalid_client** ("OAuth 클라이언트를 찾을 수 없음") | 앱에 붙여넣은 **클라이언트 ID가 틀렸거나** 오타/삭제됨 | 클라이언트 ID를 다시 **복사**해 붙여넣기. 앞뒤 공백·줄바꿈 없이, 끝이 `.apps.googleusercontent.com`으로 끝나는지 확인. 프로젝트를 잘못 골라 다른 ID를 복사하지 않았는지도 확인 |
| **액세스 차단됨: 권한 없음 / This app is blocked** | 필요한 API가 안 켜져 있거나 동의 화면 미구성 | **2단계**(YouTube Data API v3 "사용")와 **3단계**(동의 화면 만들기)가 모두 끝났는지 확인 |
| **"액세스 토큰을 받지 못했습니다" (앱 안 메시지)** | 클라이언트 유형이 "웹 애플리케이션"이 아니거나 리디렉션 주소가 안 맞음 | **4단계**에서 유형이 **웹 애플리케이션**인지, **5단계**에서 두 주소가 `http://localhost:8081`로 등록됐는지 확인 |
| **로그인이 며칠 만에 자꾸 풀림** | 유튜브 권한을 쓰는 테스트 앱은 승인이 **7일 후 만료** | 정상 동작임. 다시 로그인하면 됨. 계속 유지하려면 구글 검증 후 "게시"가 필요하지만, 개인용이라면 재로그인으로 충분 |
| **동의 화면/클라이언트 메뉴가 안 보임** | API가 아직 안 켜졌거나 프로젝트 선택이 잘못됨 | 맨 위 막대에 **`마이 튜브`** 프로젝트가 선택됐는지 확인하고, **2단계**로 API를 먼저 켠 뒤 다시 시도 |

---

### 요약 (한 줄 체크리스트)

1. 프로젝트 `마이 튜브` 만들고 **선택** ✔
2. **YouTube Data API v3** → "사용" ✔
3. **Google 인증 플랫폼**: 앱 이름·이메일 입력, 대상 **외부** ✔
4. **대상 → 테스트 사용자**에 **내 이메일 추가** ✔
5. **클라이언트 → 웹 애플리케이션** 만들기 ✔
6. **JavaScript 원본**과 **리디렉션 URI** 두 곳에 `http://localhost:8081` ✔
7. **클라이언트 ID 복사** → 앱 **설정 탭 > YouTube 연결**에 붙여넣고 **"구글 로그인하고 연결"** ✔
